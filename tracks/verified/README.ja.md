# CEPB Verified：第三者による検証

[English](README.en.md) | [入口](../../README.ja.md)

Verifiedは自己申告と独立した検証を区別する区分です。CoreやIntegratedの分母は変えません。第三者が確認したQuickも診断点のままです。

少なくとも2名の独立した第三者が、開発者との関係と利益相反を示し、凍結計画・資料・失敗・介入を確認し、独立した評定を残し、未使用試験や抜取り再実行で主張を照合します。公開報告には誰がどの範囲を確認したかを示します。

## 検証を依頼するための一式

- 規則・ケース版、事前固定した計画、人物定義、実装版。
- 全予定機会、実入力、送達、必要な環境結果、hashと加工履歴。
- 元の評定、欠測、反例、再試行、手動介入、変更履歴。
- 長期結果を主張する場合は登録、独立観測、実暦とscopeの根拠。
- 共有許可を得た監査資料と、公開用に匿名化した集計。

私的対話や利用者の個人情報を全面公開することは要求しません。監査者が許された範囲で正本を照合し、公開版と監査版の対応を残せます。

このパッケージは第三者が検証できる手順を提供します。認証機関、登録済み審査員、実際の認定サービスは同梱しません。CLIの `independently_reviewed` は申告情報であり、それだけでVerifiedの証明になりません。

[検証規則と報告形式](../../docs/ja/VERIFIED.md)に、独立性、照合、再検証、異議、満点時の条件を記載しています。
