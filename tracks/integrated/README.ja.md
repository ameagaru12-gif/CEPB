# CEPB Integrated：総合評価

[English](README.en.md) | [入口](../../README.ja.md)

**96項目・固定上限1000点**。Core590点に、姿H70、声I70、媒体協調J60、世界知覚K60、世界作用L70、人が感じる存在感O30、長期実証P50を加えます。認知、媒体、体験、長期の内訳も必ず報告します。

V0の文字型、止め絵、差分立ち絵、Live2D、3D、仮想身体、ロボットは実装タグとして記録します。形式名、写実性、部品数、記憶容量だけでは点を付けません。非人間型、無表情、寡黙な様式も、宣言した表現の中で観察できます。

## 手順

1. `python3 cepb.py init --track Integrated --output integrated.json` で計画を作ります。
2. [Core](../core/README.ja.md)の54項目に加えて、実際の表示・再生・sensor・作用・receiptを記録します。生成した「成功した」という物語を外界の正本にしません。
3. Oは別の利用者試験を行います。原1〜7、条件、人数、O6の逆方向回答と修復後の別回答を残し、[採点手順](../../docs/ja/SCORING.md)の運用アンカーを使います。対話機能の点に好感を代入しません。
4. Pは前向き登録した系譜と範囲を[長期観測](../../docs/ja/LONGITUDINAL.md)で追います。5には基準1・月次36・独立四半期12・年次再訪3・最終1の53判定役割を要します。月次点の平均ではなく、評価時点の累積観測窓を再評定します。
5. 全96項目が完備した場合だけ完成点を出します。必要な能力の非対応は0、欠測はnullとして固定分母を守ります。

## 満点の意味

Integratedの1000点には、全項目の5、未使用課題と独立照合、重大ゲートの解消、最終構成の再評価、系譜と新しい認定範囲の36暦月の前向き実証が必要です。実際の規則公開・登録・有効な独立観測が揃う前には時計は始まりません。このフォルダを作っただけでは登録済みになりません。

36暦月未満は全P項目の上限4なので、算術上限は990点です。成熟後も新scopeのP4上限が4なら1000点に届きません。観測不足ならPはnullです。CLIの集計や自己申告だけで満点認定を発行できません。

姿・声を使わないシステムはCoreや個別クラスで比較できます。Integratedで非対応項目を除外して分母を縮め、1000点へ正規化することはできません。
