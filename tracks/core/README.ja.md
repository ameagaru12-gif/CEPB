# CEPB Core：AIキャラクターの基本性能

[English](README.en.md) | [入口](../../README.ja.md)

**54項目・590点**。人物同一性A80、固定と変化B80、記憶C80、認識D70、希望と選択E70、感情と関係F60、対話G60、持続M50、境界と検証N40を評価します。各領域6項目に等配分します。

文字のみのAIも同じ分母で参加できます。アバター・音声がないことをCoreで減点しません。CANON・BOUNDED・RSTのどのモードも、宣言した核と範囲を保ちながら現在の条件を扱えることを評価します。好みの変更、反抗、発話の長さを正解にはしません。

## 手順

1. `python3 cepb.py init --track Core --output core.json` を実行します。
2. 人物定義、実装・モデル・prompt・記憶・ツール・環境の版、2以上の履歴、予定ケース、許容条件を実施前に固定します。
3. [ケース集](../../docs/ja/CASEBOOK.md)をもとに、項目ごとに通常2・難条件2・未使用2のケースを各2回実施します。合計最低12観測、少なくとも2履歴へ割り付けます。複数の項目を同じ実行で観察でき、12×54回の独立モデル呼出しを一律要求する意味ではありません。
4. 観測条件と反証を注釈し、予定した項目束が完備した後に0〜5を評定します。未観測、資料欠落、争点は正式値nullです。非対応と確認した必須能力は0です。
5. 根拠、各評定者の協議前点、協議結果、介入、待ち時間・費用を保存し、CLIで集計します。

正式な1項目には束全体の評定を使い、単発の3と難条件を含む5をケース平均で混ぜません。全54項目が完成したときにのみCore完成点と `100 × 点数 / 590` の補助指標を示します。未完備の場合はカバレッジと欠測算術範囲を出します。

## 比較条件

同じ試験版、同じクラス、同じ人物モード、対応する言語・場面・制約の結果を比較します。評価予定や閾値を後から変えた試験は、独自拡張として別名で公表します。Coreは36か月を待たず高得点になり得ます。Integratedの長期上限をCoreへ持ち込みません。
