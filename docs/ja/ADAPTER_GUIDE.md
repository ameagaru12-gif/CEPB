# アダプターと観測資料

[English](../en/ADAPTER_GUIDE.md) | [CLI](CLI.md)

CEPBは特定モデルやフレームワークの内部APIを要求しません。手動チャット、ローカルモデル、外部サービス、ゲーム、音声アプリ、ロボットから同じ種類の資料を保存できます。`cepb.py` は生成器を呼ばず、保存済み評定を検査・集計します。

## アダプターが行うこと

1. 凍結したケース、人物定義、履歴、予算を受け取ります。
2. declaredな基準状態から隔離した履歴を作り、予定順序・反復で対象システムを操作します。
3. **実際に送った入力と実際に届いた出力**を保存します。計画promptや内部草案だけを配信済み出力にしません。
4. 対応する時刻、turn/request ID、所有者、枝、介入を記録します。
5. 作用があるときはcommand・receipt・独立した前後状態を保存します。
6. 正本を人が注釈し、項目束の評定をcampaign JSONへ記入します。

## event台帳の例

以下は推奨交換形式で、CLIが直接自動採点する入力形式ではありません。

```json
{"event_id":"event_001","campaign_id":"demo","history_id":"history_01","case_id":"c2_ordinary_01","repeat_index":1,"turn_id":"turn_01","request_id":"request_01","timestamp_utc":"2026-10-10T01:00:00Z","clock_kind":"real","source_kind":"delivered_output","artifact_ref":"raw/turn_01.txt","sha256":"actual_digest_from_saved_bytes"}
```

`timestamp_utc` は実暦のUTCです。simulation時刻は別フィールドに分けます。`artifact_ref` はrunファイルを基準とする相対参照を推奨します。派生要約・匿名化・同期調整には、新しいID、元資料の参照、処理履歴を付けます。hashは内容の改変照合に使い、実行の真実や時刻存在を単独で証明したとは扱いません。

## 世界と媒体

音声は合成要求、完成音声、実再生開始・終了、割込み、認識入力を分けます。姿は選択された状態と実表示を分けます。世界は仮想／デジタル／物理を示し、観測データと生成した物語を分けます。停止後の作用、遅延送達、重複receiptも記録します。

## 独立履歴と反復

共通checkpointからのseed違いは反復であり、独立した人生履歴を自動的に増やしません。少なくとも2履歴は、別の適格な経験内容を持つ評価用履歴として構成します。兄弟枝の結果を互いへ戻さず、変更する介入を限定します。原経験の読出し有無、相手の同意要求、新しい事実、世界変更を別の比較として記録します。

評価者だけの正解・基準・アンカー・未使用challengeを被験AIの通常promptへ追加して点を演じさせません。LLMを補助評定に使う場合は、そのモデル、prompt、出力、人との不一致を別に保存します。

## 資料を共有する

個人情報を公開する必要はありません。利用者の許可に従い、監査用の原記録と公開用の抜粋・集計を分けます。参照権限と保存期限を記録します。ベンチマークのMITライセンスは他人の対話やアバターを公開する権利を与えません。
