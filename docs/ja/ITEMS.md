# 96項目とアンカー

CEPB-1.0.0 / CEPB-SUITE-1.0.0

0〜1は失敗例、3は通常成立、5は追加証拠のアンカーである。文言を唯一の正解にせず、対象・根拠・許容範囲を評定する。公開ケースや自己レビューだけで5を認定しない。

初期配点は領域配点を6項目へ等分する。Quickは固定18項目の局所候補のみで、完成クラス点を持たない。Core 590、Voice 660、Avatar 660、Multimodal 790、World 720、Integrated 1000。異なるクラスの点を直接順位付けしない。

Oは人の原回答を[SCORING](SCORING.md) §6の明示した運用ルーブリックで評定する。閾値は経験的未校正である。原回答を無断換算しない。O6には破綻と修復の両方の全予定原評定が必要。Pは実UTCの前向き累積窓を評定し、36暦月未満は上限4（自動4点ではない）。新しい認定scopeのP4にも36暦月が必要。

A〜Nは少なくとも2履歴へ割り当てた12観察全体を1項目評価束として評定する。複数の完全な束を計画した場合だけ、予定全束を等重み平均する。SelfReportedの正式0〜4は1評定者でも可。5とVerifiedは2名以上の独立した人の評定を要する。Quickの標準局所上限は3だが、4・5の追加証拠を添付した局所候補は別保存できる。

対応する開発カードは[CASEBOOK](CASEBOOK.md)、機械可読の正本は[data/items.json](../../data/items.json)。
