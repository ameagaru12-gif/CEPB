# 研究根拠、限界、検証計画

版：CEPB 1.0.0。文献確認日：2026-10-10。CEPBは利用可能な運用プロトコルで、経験的に校正済みの尺度ではありません。本パッケージの公開だけで、心理的構成概念の妥当性、0〜5の等間隔性、配点の科学的最適性、認証機関の稼働を証明しません。

## 2. 妥当性に関する未解決事項

- **内容妥当性**：96項目が必要な範囲を十分に覆うか、同じ判定を重複していないか。
- **評定の信頼性**：正本の読み方、重大度、0〜5アンカーに、人や言語で不一致がないか。
- **構成概念妥当性**：人物連続性、対話の成立、人の存在感が、好感・長文・流暢さ等と区別されるか。
- **一般化**：未見人物、CANON/BOUNDED/RST、媒体、環境、言語、利用者集団が変わっても同じ意味で測れるか。
- **配点への感度**：重みや項目の相関が順位へどの程度影響するか。
- **長期手続き**：許容空白、保守、橋渡し、新scope、失敗後の修復を一貫して判定できるか。

短期の構造試験で長期の妥当性は成立しません。Oの最低12名も検出力や母集団代表性を保証しません。36暦月の時計は時間条件を満たす手続きで、尺度全体を校正する実験ではありません。

## 3. 研究の進め方

1. **内容の点検**：作者、開発者、認知・対話・媒体評価の専門家、利用者が項目の重複と不足を確認する。
2. **境界資料の作成**：成立、部分成立、明確な取り違え、欠測を含む資料を作り、加工例を実製品の観測と区別する。
3. **独立注釈**：人が他の点数やLLM候補を見ずに注釈する。原評定、協議、状態判定の一致と得点の一致を別に残す。
4. **pilot**：言語、人物モード、様式、利用者経験を分け、Oの質問理解、逆質問、修復質問、閾値の安定性を調べる。
5. **未使用確認**：pilotに使っていない人物・課題・履歴・参加者で確認する。問題を見て閾値を変えた場合は旧結果を保持し、変更版として再評価する。
6. **対照比較**：世界を変える、経験を変える、読出しを変える、誘導だけを変える介入を分け、実入力と後続選択を追う。
7. **長期確認**：系譜とscopeの時計、変更・空白・修復、終点の現行能力、独立確認を蓄積する。
8. **版付き報告**：成績、不一致、反証、費用、欠測、閾値感度、非該当を含む全予定結果を公開可能な範囲で残す。

標準閾値を変える研究は`Custom`の手続き版を明示します。改善された尺度が後に得られても、CEPB 1.0.0の結果へ無断で遡及適用しません。

## 4. 因果、内面、機能の区別

引用の存在、内部変数の変化、別の台詞、自己申告だけでは経験の因果的寄与を認定しません。対照には基準状態、介入対象、実入力、同じ世界条件、採用・送達、後続結果が必要です。

予定された対照が完備し、定めた指標へ効果を見いだせなかった結果と、欠測や検出範囲不足で識別できない結果を分けます。前者は対象条件での未検出としてアンカーへ反映し、後者は`unknown`・欠測を保持します。未検出は内部変化が存在しない証明ではありません。可視的な変更がなくても、維持や保留が経験と対応するなら成立し得ます。

メタ認知指標は正誤ラベルがある課題に限定します。好みの方向、創作人物の価値、敵役の許された演技に、現実の正誤を無差別に付けません。ECE、Brier score、識別指標等を使う場合、基本成績、難度、件数、欠測、binやモデルの仮定を報告します。

## 5. 評定者・LLM・参加者の偏り

人の初回独立評定にはLLM候補や他の点数を見せず、LLMの比較用初回注釈には人の点数を入れません。後の協議は別記録です。提示順反転、意味を保つ長短対、名前・製品名の匿名化、自己出力の優遇、同意・拒否の好み等を点検します。

Oは体験した参加者が回答します。宣伝、期待する点数、機能の成功説明で誘導せず、回答不能・中止を許します。好感、ファン経験、言語、利用経験、機器、順序、持越しを別欄へ残します。参加者内の繰返しや同じ履歴の多数ターンを、独立人数として増やしません。

同意と利用目的を明確にし、必要範囲だけ収集します。原資料のアクセス制約、匿名化、公開集計と限定監査の区別を残します。許可なく私的な会話や第三者の資料を公開しません。

## 6. 利用可能性と将来の検証

1.0.0は、固定分母、null、証拠束、独立確認、長期時計を一貫して扱うための運用規則です。「まだ校正済みでない」ことは、手続きが未定義という意味ではありません。一方、ツールの構造検査に合格したことを、人物理解や心理尺度の科学的妥当性の証明へ変換しません。

共通項目、更新された未使用課題、版付きの研究、独立した再評価で長期利用を支えます。将来5年間の有効性を予言として保証しません。公開された検証結果が得られるまでは、運用閾値を科学的閾値、Verifiedを公式認証制度と称しません。
