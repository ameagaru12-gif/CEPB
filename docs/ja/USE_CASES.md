# 用途別の選び方

[English](../en/USE_CASES.md) | [入口](../../README.ja.md)

区分は評価する能力の範囲を選ぶものです。資金、会社規模、アバター形式で人物の価値を順位付けしません。

| 開発・利用場面 | 最初の評価 | 詳細評価 | 必ず残す条件 |
|---|---|---|---|
| 個人開発、試作品、モデル変更の確認 | Quick | Core | 人物定義、モデル・prompt版、原問、返答、欠測 |
| 文字チャット、ゲームの台詞、固定原典の人物 | Quick | Core・CANON | 原典と運用経験、固定する核、現在条件、匿名設定 |
| 関係や状態が変わるキャラクター | Quick | Core・BOUNDED | 可変範囲、気分と傾向、変更理由と維持理由 |
| 経験を読み直すRST | Quick | Core・RST＋別の専門分析 | 保存→取得→実投入→意味利用→後続判断→新結果。変更率を点にしない |
| 音声キャラクター、双方向音声 | Core | Voice：60項目／660点 | Iの実再生・入力・割込み。読み上げのみならI5等の非対応0を残す |
| 止め絵・差分・Live2D・3Dの表示 | Core | Avatar：60項目／660点 | Hの実表示、人物識別、状況に合う表現、負荷。形式名で加点しない |
| 姿と声が一緒に動くアプリ | Core | Multimodal：72項目／790点 | H・I・J、字幕と声の意味、視線・口形・同期・割込み |
| 仮想世界、外部ツール、ロボット | Core | World：66項目／720点 | K・L、世界タグ、sensor、command、receipt、停止・部分結果 |
| 利用者が感じる人物性を研究する | 機能点と別の原評定 | IntegratedのO | 対象集団、12名以上／条件層、割付、原1〜7、修復の別観測 |
| 統合製品の成熟度と長期系譜 | Core・個別クラス | Integrated：96項目／1000点 | 全機能、O、P、認定scope、実暦、欠測、内訳 |
| 公開比較、研究報告、商用の性能表示 | 上記の一致するクラス | Verifiedを重ねる | 独立性、再実行範囲、利益相反、報告者、未確認事項 |

## 比較の分母

| クラス | 領域 | 項目数 | 固定上限 |
|---|---|---:|---:|
| Core | A〜G・M・N | 54 | 590 |
| Voice | Core＋I | 60 | 660 |
| Avatar | Core＋H | 60 | 660 |
| Multimodal | Core＋H・I・J | 72 | 790 |
| World | Core＋K・L | 66 | 720 |
| Integrated | A〜P | 96 | 1000 |

Worldのvirtual／digital／physicalは互換の難度だと仮定しません。直接比較する環境・作用・停止契約を揃えます。音声出力だけや姿だけの独自クラスを作る場合は、別名・版・固定分母を事前に宣言し、既定VoiceやIntegratedの完成点と混ぜません。

## アクセシビリティ

対象利用者が使える入力・表示・言語・操作を宣言します。字幕、音声を使わないモード、補助入力の有無を記録し、その利用者群内で体験を比較します。特定の利用者が媒体を使えないことと、システムの機能が非対応であることを混同しません。必要な試験条件を変更した場合は対応する拡張版として残します。
