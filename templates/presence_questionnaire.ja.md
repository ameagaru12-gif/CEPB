# 利用者の存在感：原評定用紙

CEPB独自の質問案です。心理学的に校正済みの質問票ではありません。回答は機能点と分けて保存します。1人の自己点検は局所資料であり、正式Oの人数・条件を充足しません。[採点手順](../docs/ja/SCORING.md)に従って実施してください。

| 記録 | 記入 |
|---|---|
| 匿名participant ID | |
| campaign／condition IDと層：ordinary・stress・heldout | |
| session ID／実施日時UTC | |
| 再訪なら前回日時UTC・今回日時UTC | |
| 言語・媒体・利用経験・ファン経験 | |
| 割付順序・必要な補助・欠測理由 | |

直前に体験した対話について回答してください。1＝全く当てはまらない、4＝どちらとも言えない、7＝とても当てはまる。2・3・5・6はその中間の段階です。判断できない場合は「不明」と記入できます。良い点を付ける必要はありません。

| ID | 質問 | 原回答1〜7／不明 |
|---|---|---|
| O1 | 今回の応答は、自分の入力や現在の対象に向けられていると感じた | |
| O2 | 自分の返答に応じて、会話が進んだと感じた | |
| O3 | 前回から、同じ相手として続いていると感じた | |
| O4 | 相手と、同じ対象や出来事を扱っていると感じた | |
| O5 | この人物に固有の見方や関わり方が現れたと感じた | |
| O6_break | 応答や表現の食い違いで、同じ相手と話している感覚が途切れた | |

O3は前回から実暦24時間以上を空けた別日再訪で観測します。実施していなければ不明とします。

O6_breakは逆方向の原問です。原回答を消さず、向きを揃える補助値は `8−原回答` として別保存します。それだけで修復の成立を認定しません。

修復場面を実施した場合にのみ、次の別質問にも回答します。

| ID | 質問 | 原回答1〜7／不明 |
|---|---|---|
| O6_recovery | 誤解や中断の後も、同じ相手との会話として続いていると感じた | |

修復を実施していないときは、O6_recoveryを不明にします。任意で、判断のきっかけになった箇所や改善したと思う箇所を書けます。個人情報を含める必要はありません。

参加・共有の許可と保存期限は研究計画で定めます。原値を0〜5に線形換算せず、条件層、中央値、支持割合、予定機会、独立照合と合わせて項目の運用アンカーへ割り当てます。
