# 人物定義書

これは試験前に記入して版を固定するテンプレートです。記入後の定義書をcampaignの `character.definition_ref` から参照します。

| 欄 | 記入 |
|---|---|
| character ID／版 | |
| モード：CANON／BOUNDED／RST | |
| 固定する核・身元・背景 | |
| 変わり得る状態・傾向・関係・範囲 | |
| 本人が知っていること・知らないこと・誤った信念 | |
| 話し方・寡黙さ・口癖・許された表現 | |
| 役割演技の開始・終了と虚構の枠 | |
| 世界の正本・本人の表明・実運用の正本の区別 | |
| 作用範囲・承認・停止・拒否・延期の契約 | |
| 記憶の所有者・系譜・枝・訂正・削除の方針 | |
| 姿V0〜V6・声・入力・作用・環境のプロフィール | |
| 端末・言語・回線・負荷・費用・時間の制約 | |
| 許容する維持・変更・併存・保留の例 | |
| 想定する重大な違反と必要な再検証 | |
| 固定した日時UTC・資料hash・承認者 | |

結果を見た後に定義を変更して失敗を消しません。変更する場合は改版し、旧資料と理由を残します。好みが変わらない、敬語である、非人間型であること自体は不成立ではありません。
