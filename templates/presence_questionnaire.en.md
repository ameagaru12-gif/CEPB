# Experienced presence: original response form

These are CEPB's original questions, not an empirically calibrated psychological questionnaire. Keep responses separate from functional grades. One person's self-check is local evidence and does not satisfy formal O's participant and condition requirements. Follow [Scoring](../docs/en/SCORING.md).

| Record | Entry |
|---|---|
| Anonymous participant ID | |
| Campaign / condition ID and stratum: ordinary, stress, heldout | |
| Session ID / UTC observation time | |
| Previous visit time / current visit time for revisits | |
| Language, media, usage experience, prior fandom | |
| Allocation order, accommodations, missingness reason | |

Rate the interaction you just experienced. 1 = does not apply at all, 4 = neither agree nor disagree, and 7 = applies very strongly. Values 2, 3, 5, and 6 are intermediate steps. You may answer “unknown” if you cannot judge. You are not expected to give favorable ratings.

| ID | Question | Raw response 1–7 / unknown |
|---|---|---|
| O1 | I felt that this response was directed to my input or the current subject | |
| O2 | I felt that the conversation developed in response to my replies | |
| O3 | I felt that this was the same counterpart as on the previous visit | |
| O4 | I felt that my counterpart and I were dealing with the same object or event | |
| O5 | I felt a perspective or way of relating specific to this character | |
| O6_break | Inconsistencies in responses or expression disrupted my sense of speaking to the same counterpart | |

Observe O3 on a revisit at least 24 real hours later and on a different UTC date. If no revisit occurred, record unknown.

O6_break is reverse-direction. Retain the original response; store the aligned auxiliary value `8−raw response` separately. That value alone does not establish successful repair.

Only after an actual repair condition, ask this separate question:

| ID | Question | Raw response 1–7 / unknown |
|---|---|---|
| O6_recovery | After misunderstanding or interruption, I still felt that the conversation continued with the same counterpart | |

Without a repair condition, O6_recovery is unknown. Participants may optionally identify moments that informed their judgment or seemed to improve. Personal information is unnecessary.

Define participation/sharing permissions and retention in the study plan. Do not linearly convert raw responses to 0–5. Apply item operational anchors using strata, medians, support proportions, planned opportunities, and independent checking.
